# Morte Lenta - Cervejaria IoT com ESP32

Projeto de automação de uma cerveja artesanal utilizando ESP32 para monitoramento e controle de temperatura e controle de umidade do processo de produção.

---

## Sobre o Projeto

O *Morte Lenta* A Cerveja Mais Irada do SubMundo.

---

## Tecnologias Utilizadas

- ESP32
- Arduino IDE
- C/C++ (ESP32)
---

## Estrutura do Projeto

morte-lenta/
├── esp32/
│ └── main.ino # Código principal da ESP32
├── README.md # Documentação do projeto
└── .gitignore 


---

## Como Executar

1. Instale a Arduino IDE
2. Configure a placa ESP32
3. Abra o arquivo
4. Conecte a ESP32 no computador
5. Faça o upload do código

---

##  Funcionalidades

- Monitoramento de temperatura
- Controle de processos de fermentação
- Integração com sistema web (futuro)
- Dashboard para visualização de dados

---

## Objetivo

Criar uma solução inteligente e automatizada para cervejaria artesanal, utilizando conceitos de IoT e sistemas.
